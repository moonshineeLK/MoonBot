# MoonBot
A mini chatbot that is fun to talk with and remembers your last mood. Gives you fun and warm responds.

# 💻 How to run it on mobile
pydroid 3 is a app available on playstore in Android. You can use it go write and run codes on your mobile.

step-1: Download pydroid 3 app from playstore 

step-2: Open it and make a new file.

step-3: copy paste the code from here and saved the file as MoonBot.py

step-4: click the yellow play button at the side bottom to run the code. That's it!
